# TestProject

Unity 6（URP）测试项目。

## 环境要求

- Unity **6000.3.26f1**（见 `ProjectSettings/ProjectVersion.txt`）
- [Git LFS](https://git-lfs.github.com/)（首次克隆后执行 `git lfs install`）

## 仓库说明

本仓库采用 Unity 标准版本控制约定：

- 提交：`Assets/`、`Packages/`、`ProjectSettings/`
- 忽略：`Library/`、`Temp/`、`Logs/`、`UserSettings/` 等本地生成目录

克隆后直接用 Unity Hub 打开项目根目录即可。
